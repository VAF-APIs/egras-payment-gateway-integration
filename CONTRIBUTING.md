# Contributing

Contributions are welcome, especially tests, documentation and fixes. This project is maintained by
[Visual App Foundry](https://vaf.ai).

1. Fork the repository and create a feature branch.
2. `pip install -r requirements-dev.txt`
3. Run `python -m pytest -q` and add a test for any behaviour change.
4. Never include credentials, government documents, production IDs or personal data in commits,
   issues, examples or logs.
5. Keep state- or vendor-specific protocol code inside the adapter files, not in the shared service code.

For commercial integration or support, contact us at [vaf.ai](https://vaf.ai).
