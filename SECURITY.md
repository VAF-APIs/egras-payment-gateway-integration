# Security

This project is an open-source starter from [Visual App Foundry](https://vaf.ai). It is not a
certified government system. Review it and harden it before handling real money or citizen data.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's private "Report a vulnerability" (security
advisory) on this repository, or contact Visual App Foundry through [vaf.ai](https://vaf.ai).

## Responsible use

- Never commit real credentials, keys, tokens, government integration documents or personal data.
- Keep `.env` private. In production, use environment variables or a secret manager.
- Replace every example secret with a unique random value.
- Never expose mock gateways, demo OTP hints or demo authentication on a public server.
- Connect to government systems only with written authorisation and their official specification.

All names, IDs, numbers and URLs in this repository are fictional demo data.
